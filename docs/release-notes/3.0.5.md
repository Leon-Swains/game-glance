# Game Glance 3.0.5

This release delivers major visual customization controls, accessibility enhancements for collection cards, full controller gamepad support for the library zoom transition, and critical stability fixes for PC handhelds and custom Linux distributions (such as CachyOS).

## What's New

### 🎮 Controller 'A' Button Zoom Animation in Spotlight Library
- Fixed an issue where pressing the gamepad **A** button (or `GamepadButton.OK`) on a focused game in Spotlight Library would skip the zoom animation and transition immediately.
- Gamepad activations now accurately track the focused card element coordinates and launch the smooth 480ms zoom-into-fullscreen transition, matching touch and mouse interactions.

### ✨ New "Visuals & Effects" Settings Section & Zoom Transition Toggle
- Added a dedicated **Visuals & Effects** section in the Game Glance settings menu.
- Added **Zoom into full screen** toggle (enabled by default): users who prefer instant navigation can now disable the zoom animation entirely across both Spotlight Home and Spotlight Library.

### 🌑 "Unhighlight Uninstalled Games" Option
- Added a new **Unhighlight uninstalled games** setting under Visuals & Effects (disabled by default).
- When enabled, games that are not currently installed on your device receive a subtle, desaturated neutral gray accent (`#707784`) instead of vibrant colored highlights.
- In addition, the horizontal gallery artwork for uninstalled games is automatically rendered in sleek grayscale (85% grayscale on posters/backgrounds, 65% on logos), making installed vs. uninstalled titles instantly recognizable at a glance.

### 📐 Square Collection Tiles & Accessibility Large Text Support
- Redesigned collection cards to modern **1:1 square tiles** (`aspect-ratio: 1 / 1`), preventing card overlap when large system fonts or accessibility text scaling is active.
- Collection titles now support up to 2 lines of text with clean word-wrapping and ellipsis (`...`) clipping for long names, accompanied by badge pills indicating the game count.

### 🛡️ Critical Fix for PC / CachyOS & Custom Decky Router Environments
- Resolved a crash on startup/navigation: `TypeError: Class constructor LibraryErrorBoundary cannot be invoked without 'new'`.
- Refactored `LibraryErrorBoundary`, `HomeErrorBoundary`, and `ErrorBoundary` into hybrid callable constructor components compatible with environments where Decky Loader's router patches invoke component factories directly without `new`.
- Fixes library screen crashes and black screen lockups reported on CachyOS, Bazzite, and desktop Decky setups.
